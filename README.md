Учебный репозиторий с примерами реализации:
- Бинарная куча
- Биномиальная куча
- Куча Фибоначчи
- Хэш-таблица

## Теоретические определения

### Бинарная куча
Полное бинарное дерево, где каждый узел <= (min-heap) или >= (max-heap) своих потомков.

### Биномиальная куча
Набор биномиальных деревьев, удобна для операции объединения.

### Куча Фибоначчи
Структура на основе леса деревьев, оптимизирована для операций уменьшения ключа.

### Хэш-таблица
Структура для хранения пар ключ–значение с быстрым доступом по хэш-функции.
